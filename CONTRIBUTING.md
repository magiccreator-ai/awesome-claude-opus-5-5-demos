# Contributing

## Suggest a demo

Open an issue with the **Suggest a demo** template. You do not need to edit JSON.

Please provide:

- A link to the original creator's post and their name or handle.
- A short explanation of what was built and how Claude Opus 5.5 was involved.
- A live demo and GitHub or source-code link, when the creator made one available.
- Other tools used, known limitations, and any sponsorship disclosure.

We collect concrete projects and workflows, not standalone prompts, unattributed reposts, or unsupported benchmark claims. A recording is welcome when no live demo exists; do not invent a link or describe a recording as playable.

## Corrections and removals

Open an issue identifying the case and requested correction or removal. Include the original source where possible. Do not upload someone else's video, project files, or private material.

## Pull requests

README.md is generated from a maintained catalog. Suggest cases and corrections through issues instead of editing the generated README directly. Improvements to these contribution instructions and issue templates are welcome.
